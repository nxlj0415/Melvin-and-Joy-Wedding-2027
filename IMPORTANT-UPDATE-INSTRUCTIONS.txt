MELVIN & JOY RSVP — DUAL CONFIRMATION FIX

Google Sheets already saves the RSVP. This package improves the confirmation mechanism using both a JSONP status lookup and a hidden iframe status lookup. It redirects to thank-you.html ONLY when a matching Submission ID is verified.

1. In your Google Apps Script editor, replace Code.gs with google-apps-script.gs from this ZIP. Save.
2. Deploy > Manage deployments > Edit (pencil) > New version > Deploy. Keep the existing Web App URL and Anyone access.
3. In GitHub, upload/replace script.js and thank-you.html from this ZIP (or upload all website files). Commit.
4. Wait for GitHub Pages deployment, then press Ctrl+Shift+R. Submit ONE test RSVP.
5. Check Google Sheets and whether thank-you.html opens.

If it still says confirmation could not be verified, do not resend an already-saved RSVP. Check Apps Script Executions for doGet failures, and share a screenshot.

Do not replace your Apps Script by merely uploading google-apps-script.gs to GitHub.
