MELVIN & JOY RSVP - CONFIRMATION FIX

1. Open the Google Apps Script project Melvin & Joy RSVP 2027.
2. Replace ALL Code.gs contents with google-apps-script.gs from this ZIP. Save.
3. Deploy > Manage deployments > Edit (pencil) > Version: New version > Deploy.
   Keep Execute as: Me and Who has access: Anyone.
   Keep the SAME existing Web App URL (already in script.js).
4. Extract this ZIP and upload the website files to the ROOT of your GitHub Pages repository.
   Replace script.js and other matching files, then commit changes.
5. Hard refresh the published page (Ctrl+Shift+R). Submit ONE test RSVP.
6. Verify a row is saved in the RSVP Responses sheet and the thank-you page opens.
7. Check email notifications separately; email delivery is not guaranteed by row saving.

WHY THIS FIX: The previous version saved rows but did not reliably send a browser confirmation
across Google's embedded web-app frame. The new version checks the sheet by the unique
submission ID before redirecting. If confirmation is unavailable it does not falsely
claim success. Resubmissions reuse the same ID to reduce duplicates.

SECURITY: The status endpoint only returns whether a supplied random submission ID exists.
